## 3. UTAUT2 mapping

The questionnaire uses TAM items, which map onto three UTAUT2 constructs. The other UTAUT2 constructs were **not measured**.

| UTAUT2 construct | Source | Mean (est.) | Evidence |
|---|---|---|---|
| Performance Expectancy (PE) | TAM PU | 4.15 | "This feature is useful" (U04, U05, U06). "Summarises everyone's free dates correctly and quickly" (U08) |
| Effort Expectancy (EE) | TAM PEOU | 3.85 | 95% task success. Confusion over yellow (5/10) and schedule period (4/10) |
| Behavioral Intention (BI) | TAM BI | 3.95 | Requests for future features (Google Calendar, reminders) imply intent to keep using |
| Social Influence (SI) | not measured | — | Qualitative only: U01 worried others wouldn't understand "I used Singto" |
| Facilitating Conditions (FC) | not measured | — | Qualitative only: runs inside LINE, which every participant already uses. One user wanted Thai UI (added in [`b083245`](https://github.com/Eng-Guan-Jie/Singto/commit/b083245)) |
| Hedonic Motivation (HM) | not measured | — | — |
| Price Value (PV) | not applicable | — | Free service |
| Habit (HT) | not measured | — | Would need a longitudinal study |

## 4. Limitation of the estimates

Users with lower estimated SUS (U03, U06, U07) were the ones who needed 2–3 help requests or had a Partial result. The highest scorers (U01, U09, U10) needed no help. Because the estimates were partly derived from task performance, this correlation is built in and cannot be used as evidence. Real responses (§6) remove that limitation.
